COMPARATIVE BIG DATA ANALYTICS
Online Food Delivery Platforms and Restaurant Data
=================================================================

1. PROJECT OBJECTIVE
This project explores restaurant and online food-delivery data using data cleaning, quality checks, exploratory analysis, and summary reports. The goal is to identify patterns in ratings, prices, delivery estimates, restaurant categories, cuisines, and menu records.

3. CROSS-DATASET LIMITATIONS
- The datasets represent different geographies, collection periods, currencies, and units of observation.
- Restaurant records, menu-item records, and platform listings are not interchangeable.
- Ratings may be defined differently across sources.
- Price fields may represent an individual item, a meal for two, or another source-specific convention.
- Delivery estimates and fees are historical snapshot values and should not be presented as current live information.
- Therefore, raw averages should not be used to rank platforms without harmonizing definitions and units first.

4. FUTURE ANALYSIS
- Build charts for ratings, prices, cuisines, and locations.
- Standardize currency, time period, and metric definitions where possible.
- Compare platforms only on fields that are genuinely comparable.
- Document missing values, outliers, and assumptions.
- Use Spark for distributed processing where appropriate and Python streaming for large CSV outputs when the Windows environment does not support Spark file writing.
